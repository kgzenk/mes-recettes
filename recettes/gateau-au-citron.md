# Préparation

1. Préchauffez le four à 160 degrés (chaleur tournante).
2. Mélangez le beurre (plutôt mou), le sucre, et les œufs afin d’obtenir un mélange homogène et légèrement mousseux.
3. Ajoutez la pincée de sel, la zeste d’au moins deux citrons (ou davantage si vous aimez bien le goût), les amandes en poudre, la farine, ainsi que la levure chimique.
4. Faites cuire le gâteux dans un moule à cake dans le four pendant 50 à 60 min. Pour vérifier que le gâteau soit bien cuit, piquez le centre du gâteau avec un cure-dent, il doit ressortir propre et sec. 
5. Pendant que le gâteau refroidisse dans le moule, avec un cure-dent, faites une série de trous (4 × 12) dans la partie supérieure de votre gâteau. Avec une seringue, « vaccinez » le gâteau avec le jus de tous les citrons dans les trous que vous venez de faire.
